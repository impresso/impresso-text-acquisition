RTS AudioDoc importer
=====================

This importer is a special case of AudioDoc format which is an output of the Whisper Algorithm.
It was developed to handle ASR radio data provided by the `Radio Télévision Suisse (RTS)
<https://www.rts.ch/>`_ of Switzerland.
